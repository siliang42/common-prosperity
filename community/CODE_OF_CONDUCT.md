# 社区准则

这个社区讨论加密资产量化工具，参与者背景差异很大。为了让讨论保持有用，请遵守下面几条。

## 我们鼓励

- **拿证据说话**：给出样本区间、参数、样本外结果，而不是只给结论
- **公开失败**：走不通的路同样有价值，写清楚为什么走不通
- **就事论事**：批评代码、方法和结论，不针对人

## 我们不接受

- 人身攻击、歧视性言论、骚扰
- 荐股荐币、承诺收益、招揽资金、代客理财
- 拉群、导流、变相广告
- 未经许可公开他人的策略、代码或私人信息
- 发布或索要 API key、私钥、助记词

## 关于风险

加密资产波动极大，社区里的任何内容都是技术讨论，不构成投资建议。
按别人的结论下单，损失由自己承担。

## 执行

违规内容会被删除，反复违规会被移出组织。
需要私下沟通或被举报时，联系组织 Owner。

本准则适用于组织内的仓库、Issue、Discussions、PR 评论，以及在社区名义下的其他场合。
