## 关于

一个讨论量化方法与工具、沉淀可复用知识的社区。

不追求覆盖广度，只把用得上的东西写清楚：方法有没有效、边界在哪、什么情况下会失效。

## 参与

- **Discussions** — 提问、想法、复盘
- **Issues** — 可复现的问题与明确的需求

提问前先翻一遍已有讨论，很多问题已经有结论，包括那些最后证明走不通的路。

## 边界

- 不推荐具体标的，不做收益承诺
- 不代客理财，不接受资金委托
- 不提供实盘交易信号

任何内容都是技术讨论，不构成投资建议。
